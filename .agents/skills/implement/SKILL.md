---

指定された仕様に従って実装する。手順:

1. 仕様を読む (ファイルパスまたはプロンプト内のインライン仕様)。不明点があれば着手せず質問として報告する
2. `git checkout -b <短い英語名>` でブランチを切る。main への直接コミット禁止
3. 仕様の `## Scope lock` の範囲内だけで実装する。やらないことに触れない
4. 検証: `pnpm validate` が重い場合は対象に応じて `pnpm lint` / `pnpm typecheck` / 関連テストのいずれか以上を通す。何を回したか報告する
5. コミットする (pre-commit hook に従う)。push はしない
6. review スキルの基準で差分を自己レビューする。Blocker があれば直してコミット追加し、通るまで繰り返す (最大3周。3周超えたら未解決点を報告して止める)
7. 報告: ブランチ名・検証内容・レビュー結果 (Verdict)・Follow-ups

注意: 顧客名・テナント slug・顧客データ由来の具体数値をコード・コミットメッセージ・ドキュメントに書かない (docs/agent-rules/confidentiality.md)。
